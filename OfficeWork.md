# Компьютеры в офисе

В августе 2024 года столкнулся с ситуацией, когда несколько сидящих рядом сотрудников использовали беспроводные мышки и клавиатуры. Из-за "эфирного шума" при работе с мышью начинали возникать различные глюки - систематически "не срабатывали" щелчки по кнопкам мыши, происходила потеря выделения текста при перемещении курсора мыши, и т.д.

Проблему, гипотетически, можно решить выбрав не конфликтующие диапазоны частот. На практике же, единственный рабочий вариант - проводные мыши и клавиатуры.

## Пропустить создание учётной записи Microsoft на этапе установки Windows

Пропустить создание учётной записи Microsoft на этапе установки можно. Достаточно нажать Shift+F10, ввести в командную строку `start ms-cxh:localonly` и в появившемся окошке создать локальную учётную запись.

## Удалить кривое обновление Microsoft Windows

Начиная с 2024 года, Microsoft стала публиковать значительное количество обновлений системы, которые нарушают работоспособность системы. Чтобы откатить кривой update, следует зайти в режим восстановления Windows и выполнить команду

```shell
wusa /uninstall /kb:5077181 /quiet /norestart
```

Параметр `/kb:` указывает на пакет обновлений, который необходимо удалить.

## Современные ноутбуки - без Ethernet-разъёма

В современных ноутбуках исчезли Ethernet-разъёмы. Это связано с тем, что ноутбук стал действительно мобильным устройством, для которого очень странно искать провод, например, сидя в кафе на улице, или в гостинице. При этом, толщина ноутбуков уже крайне редко позволяет добавить Ethernet-разъём, который является высоким.

Если необходим именно Ethernet, то чаще всего используются адаптеры USB-C --> Ethernet.

## Бесклеевые защитные стекла: как это работает

Часть современных защитных стёкол выпускается без клеевого слоя. Самый распространённый пример — недорогие 2.5D-стёкла, у которых нет клейкой основы, поверхность на 100% прозрачная, а края скруглены. Такие модели:

- держатся за счёт статического притяжения (электростатического взаимодействия) между стеклом и экраном смартфона
- не оставляют следов при снятии
- по периметру имеют небольшие зазоры, что делает их совместимыми практически с любым чехлом
- Это самый простой и дешёвый вариант, но у него есть недостаток — на изогнутых экранах по краям могут появляться пузырьки воздуха, и держится такое стекло менее надёжно, чем клеевое

Основная проблема - совместимость с чехлами, которые могут создавать боковое давление и смещать стекла, что приводит к их отклеиванию.
